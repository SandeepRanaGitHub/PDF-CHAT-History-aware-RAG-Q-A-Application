# PDF History aware RAG Q&A Conversation Application
* The application requires your GROQ_API_KEY for running the agent.
<br>
* You can upload any PDF of your choice, the application lets you have conversation on it not only on uploaded document but also can response to general question.
<br>
* It remembers early conversation which makes it more interactive.
